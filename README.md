# カード家計簿(iPhone向けPWA)

クレジットカードの利用通知メールをGmail経由で読み取り、未精算の利用額を自動で積算します。
振込口座に引き落とし額を振り込んだら「Refresh」ボタンを押すと、合計が¥0にリセットされます。

- サーバーは使いません。データ(カード設定・取引履歴)はすべて **お使いの端末のブラウザ内(localStorage)** にのみ保存され、外部には送信されません。
- Gmailへのアクセスは、ブラウザから直接Google公式APIを呼び出す方式です(Google Identity Services + Gmail API)。

## 1. iCloud/Yahoo!メールをGmailに転送する

このアプリはGmailしか読み取れません。iCloudメールとYahoo!メールで受け取っているカード利用通知は、
事前に **Gmailアドレスへ自動転送** する設定にしてください。

- **iCloudメール**: iCloud.com の「メール」→ 設定(歯車)→「ルール」で、カード会社の送信元アドレスから届くメールだけをGmailアドレスへ転送するルールを作成します。
- **Yahoo!メール**: Yahoo!メールの設定 →「メールの転送」で、フィルタ条件(送信元アドレスなど)を指定してGmailアドレスへ転送します。

転送先は普段使っているGmailアドレスでも、このアプリ専用の新しいGmailアドレスでも構いません。

## 2. Google Cloud で OAuth クライアントIDを発行する

1. [Google Cloud Console](https://console.cloud.google.com/) で新しいプロジェクトを作成します。
2. 「APIとサービス」→「ライブラリ」から **Gmail API** を検索して有効化します。
3. 「APIとサービス」→「OAuth同意画面」を設定します。
   - User Type: 外部(External)
   - テストユーザーに自分のGmailアドレスを追加(公開審査は不要、自分専用アプリのため)
   - スコープに `https://www.googleapis.com/auth/gmail.readonly` を追加
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」を選択します。
   - アプリケーションの種類: **ウェブアプリケーション**
   - 「承認済みのJavaScript生成元」に、後述のデプロイ先URL(例: `https://your-name.github.io`)を追加します。ローカルテスト用に `http://localhost:8000` も追加しておくと便利です。
5. 発行された「クライアントID」(`xxxxx.apps.googleusercontent.com` の形式)をコピーします。

このアプリの「設定」タブにクライアントIDを貼り付けて保存し、「Googleでサインイン」を押すと初回にGoogleの同意画面が表示されます。

## 3. デプロイ(iPhoneから使えるようにする)

GISのOAuthは `https://` または `http://localhost` からのアクセスが必要なため、
社内LANのIPアドレスなどでは動きません。無料の静的ホスティングにデプロイするのが簡単です。

### GitHub Pagesの場合

```bash
cd kakeibo-app
git init
git add .
git commit -m "init"
# GitHub上に空リポジトリを作成してから:
git remote add origin https://github.com/<your-name>/kakeibo-app.git
git push -u origin main
```

GitHubリポジトリの Settings → Pages で `main` ブランチを公開すると、
`https://<your-name>.github.io/kakeibo-app/` が発行されます。このURLを手順2の「承認済みのJavaScript生成元」に追加してください。

### Vercel / Netlify の場合

このフォルダをそのままドラッグ&ドロップ、または `vercel` / `netlify deploy` コマンドでデプロイできます(ビルド不要の静的サイトです)。発行されたURLを同様にOAuthクライアントの生成元に追加してください。

## 4. iPhoneでホーム画面に追加

1. iPhoneのSafariでデプロイ先URLを開きます。
2. 共有ボタン → 「ホーム画面に追加」をタップします。
3. ホーム画面のアイコンから起動すると、フルスクリーンのアプリのように使えます。

## 5. アプリ内でカードを登録する

「カード」タブで、カード会社ごとに以下を設定します。

- **カード名**: 表示用の名前(例: 楽天カード)
- **Gmail検索クエリ**: そのカードの通知メールだけを絞り込む条件。例: `from:rakuten-card@rakuten-card.co.jp`
- **金額抽出用の正規表現**: メール本文から金額を取り出す正規表現。カッコ `()` の中に金額の数字部分だけが入るようにしてください。例: `ご利用金額[^0-9]*([0-9,]+)\s*円`

登録前に、実際に届いたメールの本文をコピーして「テスト用メール本文」に貼り付け、「抽出テスト」で正しい金額が取得できるか必ず確認してください。
メールの書式はカード会社や時期によって変わることがあるため、うまく取れなくなった場合は正規表現を見直してください。

## 6. 使い方

1. 「ホーム」タブの「Gmail同期」を押すと、登録した各カードの新着通知メールを検索し、金額を積算します。
2. 積算された「未精算合計」が振込前のカード利用額です。
3. 実際に振込口座へ引き落とし額を振り込んだら、「Refresh(振込完了)」を押すと合計が¥0にリセットされます(取引履歴自体は「履歴」タブに残ります)。
